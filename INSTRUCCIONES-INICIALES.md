# Antes de ejecutar

Copiar `PaquetesViajes/Web.config.example` a `PaquetesViajes/Web.config`.
La conexión local usa autenticación Windows; configurar el servidor y la base en el equipo.
No subir el archivo real Web.config del servidor de Somee.
El repositorio está pensado para código fuente, no para desplegar directamente desde GitHub.
